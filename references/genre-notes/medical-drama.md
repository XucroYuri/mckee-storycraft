# 医疗剧 × 麦基方法论适配（Genre Note: Medical Drama）

> 研究线 A 的第四个验证子类。与前三类（恐怖的大张力、情景喜剧的快节奏、少儿动画的价值换轨）差异化——医疗剧是**强专业场域 + 群像 + 病例单元**类型，其"医学信息密度 vs 麦基少即是多""团队群像 vs 单一主角""病例即迷你故事"带来独特的方法论张力。回答：这类常见问题是什么？《故事》方法论如何让它写得更好？

## 触发条件（硬性双门控）

**只有两个条件同时成立才加载本子类**：
1. 用户**明确**表示故事类型为医疗剧 / 医学剧（含医院背景、急诊、病例单元、医务群像；可含职业伦理、医疗悬案）。
2. 用户**明确**要求按医疗剧方法论创作 / 诊断 / 改写。

缺一不可。不满足任一条件 → **退回通用流程**（`capabilities/diagnosis-workflow.md` 或 `capabilities/outline-template.md`），不套用医疗剧适配。

**补充**：若用户做的只是"有个医生配角"的普通剧情，未明确以医疗剧方法论展开，则不加载本子类。

## 这类该怎么写得更好（方法论适配核心）

医疗剧的难点**不在医学专业知识（那是注脚，不是主角）**，而在把"病例"变成有情感与价值的真故事，同时不让节奏被专业信息压垮。麦基方法论在此的适配关键：

### 1. 病例 = 一个激励事件 / 迷你故事，而非背景板
- 每个病例本身就是一个带有价值转变的微型结构：病人入院（激励事件）→ 诊断/抢救的进展（节拍）→ 危机（两难）→ 转机或无力回天（价值转变）→ 结果（结）。
- **适配**：不要把病例当"给医生做背景的医学素材"，要让病例承载一次"生/死、信任/失误、尽力/取舍"的价值转变——麦基的场景必须价值转变，病例场景也不例外。

### 2. 医学信息密度 vs 麦基"少即是多"（核心张力）
- 医疗剧最容易掉进"术语轰炸"：满篇专业名词，观众跟丢、情感断裂。这直接违背麦基"观众不需要知道一切才开始关心"。
- **适配**：只保留推动本场价值转变所必需的医学信息；把"诊断听懂"交给角色用"行动 + 一句人话"传达（例如"他的心脏在漏血"而非一大段病理词）。专业度用"医生面对两难的决断"体现，不是用术语密度体现。

### 3. 病例与私生活互喻（潜文本 / 控制思想）
- 医疗剧的分水岭在"病例里的困境"是否与主角的**私生活困境互喻/对照**——这是控制思想（主题）的藏身处。
- **适配**：让某个病例的"保命 vs 放手""原则 vs 人情""专业 vs 良知"与主角当下的人生卡点形成同构；病例讲完了，主角也借势照见了自己。这比"病例 + 一段感情戏"两张皮高级得多。

### 4. 团队群像：麦基"复数主角"不靠平均分配
- 医疗剧常是**群像**（急诊室/科室全员）。麦基对"复数主角"有极严格条件：群体需**共同希望、同甘共苦**；否则就是"一堆主线彼此打架"。
- **适配**：把"团队共同目标"（救下这个病人 / 守住这个科室）立起来，让众角色围绕它各展其长而非各讲各的故事。个人线作为"本集的对照"穿插，而非平分秋色。

### 5. 单元 vs 季弧：病例单元为骨，角色成长为肉
- 借鉴喜剧/少儿剧经验的"单元微型结构 + 整季递进"：
  - **单元（每集病例）**：一个病例的价值转变 + 一位角色的私生活对照 + 情感落地。
  - **季弧（连续性）**：一个更大的健康/伦理/制度主题，串起病例与角色的成长（谁医愈了谁、谁改变了、谁没撑下来）。
- **适配**：病例单元承担"当集的结构"，季弧承担"整季的控制思想"，两者靠互喻咬合。

### 6. 医学的两难 = 麦基"两难困境"的天然富矿
- 医疗剧最擅长也最该用的，是**麦基的"善 vs 善 / 恶 vs 恶"两难**：救 A 需牺牲 B、守原则 vs 救人、专业判断 vs 家属意愿、真相 vs 安抚。真正的选择都有代价。
- **适配**：每个有分量的病例都给医生一个"两难"而非"明显正确"的选项；压力下的选择揭示医者真正是谁（麦基人物真相关键）。

## 常见失败模式（对照自查）

| 失败 | 为什么会失效 | 麦基适配解法 |
|------|--------------|--------------|
| 术语轰炸、观众跟丢 | 信息密度压垮情感 | 只留推动价值转变的必要信息，用"动作+人话"传达 |
| 病例只是背景板 | 没有价值转变，成医学展示 | 让病例承载一次生/信/取舍的价值转变 |
| 病例与私生活两张皮 | 互喻缺失，双线各讲各的 | 病例困境与主角人生卡点同构，借势照见 |
| 群像各讲各的 | 缺"复数主角的共同目标" | 立团队共同目标，个人线作对照不平均分 |
| 医生无所不能/永久正确 | 无两难、无敌光环 | 给每个分量病例一个"善vs善"两难逼真代价 |
| 只有冷专业、无人性 | 医生成工具人 | 压力下的选择揭示医者的真实选择与代价 |

## 分步做法

1. **确认硬门槛**：满足"类型=医疗剧 且 用户明确要求"双条件，否则回退。
2. **立团队共同目标**：和用户敲定"团队在为何而战"（救某病人/守住科室/一个更大主题），作为群像主轴。
3. **定病例 = 迷你故事**：为每个有分量的病例画出 激励→进展→两难→价值转变→结果 的微型结构。
4. **做信息减法**：把每场的医学知识砍到"够观众理解这场决定"的最少；专业靠"行动+一句人话"传达。
5. **挂互喻**：让本集病例的困境与一位主角的私生活卡点同构，作为潜文本与主题承载。
6. **给医者两难**：为关键病例设计"善vs善"的两难，让压力下的选择揭示医者真相。
7. **自查**：用上方"常见失败模式"表逐项核对。

## 输出结构

- 对**诊断**：按 `diagnosis-workflow.md` 骨架，额外核对本站第 2、3、4、6 条（信息加法 / 互喻 / 群像主轴 / 两难）。
- 对**新创作/改编**：给出 "团队轴 → 代表性病例的迷你结构 → 信息减法清单 → 互喻设定 → 医者两难" 的整套建议。

## 麦基依据

- 麦基"场景必须价值转变"——病例场景也不能例外，否则是医学展示而非戏。
- 麦基"少即是多 / 观众不需要知道一切"——医疗信息减法的理论底座。
- 麦基"复数主角须共同希望、同甘共苦"——医疗群像不平均分线的前提。
- 麦基"两难困境 / 压力下的选择揭示真我"——医学两难是天然富矿。
- 麦基"控制思想"——病例与私生活的互喻是主题藏身处。

## 边界提醒

- 本子类只服务"医疗剧该怎么写"，**不替用户做"是否做医疗向/面向谁"的定位决策**，也不提供真实的医疗操作指导（医疗细节请以专业规范为准，本站只做叙事）。
- 不把医疗剧写成"医术炫技/伦理说教"；本站一切服务于病例的情感与价值转变。
- 若用户要的是"医疗但偏悬疑/爱情"等复合类型，按主导类型或混合处理，本子类提供医疗场的叙事底座。

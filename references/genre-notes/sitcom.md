# 情景喜剧 × 麦基方法论适配（Genre Note: Sitcom / 情景喜剧）

> 研究线 A 的第二个验证子类。与恐怖片差异化对位——情景喜剧以高密度节拍、快转场、多季连载为特征，恰好检验麦基"幕 = 不可逆价值转变"等慢节奏假设在快喜剧里如何被修正适配。回答：这类常见问题是什么？《故事》方法论如何让它写得更好？

## 触发条件（硬性双门控）

**只有两个条件同时成立才加载本子类**：
1. 用户**明确**表示故事类型为情景喜剧 / 喜剧（含单元剧、多季连载喜剧、情景短剧）。
2. 用户**明确**要求按情景喜剧方法论创作 / 诊断 / 改写。

缺一不可。不满足任一条件 → **退回通用流程**（`capabilities/diagnosis-workflow.md` 或 `capabilities/outline-template.md`），不套用情景喜剧适配。

**补充**：若用户只是在剧情中写了几个笑点，未明确要求按情景喜剧方法论展开，则不加载本子类。

## 这类该怎么写得更好（方法论适配核心）

情景喜剧的难点**不在抖包袱，而在让"好笑"有结构、有情感、可持续**。麦基"好故事靠价值转变与对立力量"的命题在喜剧同样成立，但它们的结构单元被压得更密、节奏更快。适配要点：

### 1. 节拍是喜剧的最小单位（密度优势）
- 麦基的"节拍 = 动作-反应对"在喜剧里被用到极致：笑点往往就欠在一个节拍的反转上。
- 情景喜剧一集的节拍密度远高于正剧——每个场景都该在多个节拍上产反转（扑空、误会、期望落空）。
- **适配**：不把"幕 = 不可逆价值转变"硬套在单集上；单集常常只有一个次要价值转变（一个不被逼到绝境的笑点高潮），真正的"不可逆大转变"留给季终或连续的悬念弧。

### 2. 笑点必须长在情感与情境上，而非只有嘴贫
- 麦基反对"为笑而笑"。情景喜剧最广为人知的失败是"只有嘴贫、无情境、无情感底"。
- 笑点先来自**角色在压力下的选择与情境错位**（对立的擦撞），再落到台词；台词是最后一步，不是起点。
- 可复用结构：**固执的角色 × 不可调和的世界** → 每次期望落空（鸿沟）都催生笑点，也让角色处境逐层加码。

### 3. 单元剧 vs 连续剧的两套架构（结构阶梯改写）
- **单元剧（每集独立）**：每集是一个微型结构——开场确立失衡 → 中段误会/计划失控递增 → 闹剧高潮（冲突能量顶峰）→ 温柔化解。幕被压缩进一集。
- **连续剧（季弧）**：季是一个大幕；单元与单元之间靠"剧情的暗涌/关系递进"串成更大的价值阶梯。麦基的"序列→幕"在此演化为"单集→季度弧"。
- **适配**：给一套"单集微型结构" + "整季递进结构"两套骨架，避免无限单拍或反季末无力。

### 4. 角色不能是"功能性搞怪担当"，而要有欲望与两难
- 喜剧角色最易扁平（人人一个标签、一套动作）。麦基视角：真正的喜剧角色同样靠**压力下的选择**揭示——只是选择的失败以"好笑"的方式暴露。
- 每个主要角色都要有 自觉/不自觉欲望：想被认可却搞砸、想维持体面却被现实打脸——欲望与处境的落差本身就是喜剧张力。

### 5. "温柔化解"不等同于"廉价和解"
- 麦基要"冲突解除场景"给观众缓冲，喜剧尤其需要——笑够了要让角色和观众都"落地"。
- 但化解须由角色自己的选择与成长兑现（呼应季弧），而不是抛一个新的巧合强行温馨收尾。泪点与笑点同源（喜剧的内核常是让角色自嘲地承认自己的局限），才不显得空。

## 常见失败模式（对照自查）

| 失败 | 为什么会失效 | 麦基适配解法 |
|------|--------------|--------------|
| 只有嘴贫、没情境 | 没有"固执角色×阻碍世界"的对立场 | 先造情境错位与期望落空，再写台词 |
| 为笑而笑、无情感底 | 笑点不服务任何价值或关系 | 让笑点长在角色欲望的受挫上 |
| 角色功能性标签化 | 没有欲望与两难，只是工具人 | 给每人自觉/不自觉欲望 + 压力选择 |
| 单元剧只拍不连 | 无限单集孤立，无季级价值递进 | 上"整季弧"给关系/情境逐层加码 |
| 结尾靠巧合温馨和解 | 化解不由角色选择兑现，需空 | 化解由角色自嘲承认局限达成 |
| 点子枯竭、越写越干 | 只靠台词梗，剧情不推进 | 让每集"价值"在季内净变化一步 |

## 分步做法

1. **确认硬门槛**：满足"类型=情景喜剧 且 用户明确要求"双条件，否则回退。
2. **定载体骨架**：和用户敲定 单元剧 or 连续剧（多季）；据此选"单集微型结构"或"整季递进结构"。
3. **立角色欲望组**：为每个主要角色写 自觉/不自觉欲望 + 一条"想要却搞砸"的性格杠杆（固执/虚荣/过度自信等）。
4. **排节拍密度**：在每个场景里预设 2-3 个节拍反转（扑空/错位/期望落空），让笑点从情境错位里长出来。
5. **设单集或季中枢纽**：单元剧→每集一个闹剧高潮 + 温柔化解；连续剧→设计季级的关系/情境升级点。
6. **守住情感底**：笑点的同时给"角色被迫自嘲/承认局限"的落地时刻。
7. **自查**：用上方"常见失败模式"表逐项核对。

## 输出结构

- 对**诊断**：按 `diagnosis-workflow.md` 骨架，额外核对本站第 2、3、4 条（笑点情感底 / 单元vs连续架构 / 角色欲望）。
- 对**新创作/改编**：交付"单集结构"或"整季结构"的骨架 + 主要角色的欲望表 + 每场景节拍密度排布 + 情感落地时刻。

## 麦基依据

- 麦基"节拍 = 动作-反应对"是喜剧密度的理论底座。
- 麦基"对立力量 / 固执主角"——喜剧的张力来自固定性格撞上不可调和的世界。
- 麦基"压力下的选择揭示真我"——喜剧角色靠选择失败揭示好笑的真我。
- 麦基"不可逆转变"在喜剧的修正——单集让位于"闹剧高潮的次要转变"，大转变留给季/季末。
- 麦基"冲突解除场景"——喜剧的温柔化解是必需的缓冲，但须由角色选择兑付。

## 边界提醒

- 本子类只服务"情景喜剧该怎么写"，**不替用户做"要不要做喜剧/面向谁"的定位决策**。
- 不把喜剧写成"段子合集/短视频爽段"，本站一切服务于笑点的情感与价值地基。
- 若用户要的是"非喜剧的幽默元素"（剧情里带幽默但非情景喜剧），按通用流程处理即可，不套用本子类。

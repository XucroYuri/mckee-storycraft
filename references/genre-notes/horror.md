# 恐怖片 / 惊悚片 × 麦基方法论适配（Genre Note: Horror / Thriller）

> 研究线 A 的首个验证子类。针对差异极大的恐怖/惊悚片，深挖这类专属的常见失败模式，并回答：麦基《故事》的方法论如何针对性适配，让这类写得更好。

## 触发条件（硬性双门控）

**只有两个条件同时成立才加载本子类**：
1. 用户**明确**表示故事类型为恐怖 / 惊悚（含超自然、心理、环境恐怖、悬疑惊悚）。
2. 用户**明确**要求按恐怖片方法论创作 / 诊断 / 改写。

缺一不可。不满足任一条件 → **退回通用流程**（`capabilities/diagnosis-workflow.md` 或 `capabilities/outline-template.md`），不套用恐怖片适配。

**补充**：若用户只是问"恐怖片能不能这样写"或是在通用创作中顺带一句话带过恐怖元素，未明确要求以恐怖片方法论展开，则不加载本子类。

## 这类该怎么写得更好（方法论适配核心）

恐怖片的难点不在"吓不吓人"，而在于**恐惧必须有情感与价值的地基**。麦基的核心命题"好故事靠对立力量与价值转变取胜"在恐怖片同样成立，但价值坐标不同——恐怖片的价值轴通常是**「安全 ↔ 不安全感」**或**「幸存 ↔ 丧失」**，而非普通的爱/恨/成功。适配要点如下：

### 1. 让"恐"服务于"惧"（对立力量的四层堆叠）
- 单一的怪物 Jump-scare 只产生瞬时惊吓（surprise），不产生持续的恐惧（dread）。
- 用麦基的对立力量四层（内在 / 个人 / 社会 / 环境）给恐怖力量加码：怪物本身（环境）+ 主角内心的负罪与恐惧（内在）+ 周围人不信他 / 体制压制真相（社会 / 个人）。
- **核心**：对立力量越强、越复杂，主角的处境越无望，「不安全感」越深。一个只会扑杀的怪物，远不如"所有人都在不动声色地背叛主角"更让人背脊发凉。

### 2. "未知 > 揭示"与麦基悬念观的协作（关键适配点）
- 恐怖片常用「未知的想象优于全揭示」——让观众的想象比怪物恐怖一百倍。
- 这与麦基"让观众知道得比角色多制造悬念"的思路需要**协同而非对抗**：
  - **在惊吓层**：半揭示，让观众看不到全貌（保留想象）。
  - **在悬念层**：让观众比主角更早知道"危险正在靠近"（门在慢慢打开 / 脚步声逼近但主角没听见），制造麦基式悬念——观众悬着心，主角却浑然不觉。
- 好的恐怖片两种都用：观众比主角知道得多（悬念）+ 观众仍看不清怪物（未知）。

### 3. 节奏：次第升级的吓点（序列 / 幕的价值放大）
- 不能用同一种强度的吓点平铺全片，否则审美疲劳。
- 用麦基的结构阶梯次第加压：节拍（小惊吓）→ 场景（一次恐惧价值转变）→ 序列（一次次级危机）→ 幕（一次不可逆的恐怖升级）。
- 经典构造：片头半信半疑（不信恐怖)→ 首个真实威胁（信了三分之一）→ 中段证实无路可逃（信了大半）→ 高潮「逃无可逃 / 付出身份或代价」→ 结局隐患未除（开放 / 代价）。

### 4. 激励事件 = 穿越恐怖的门槛
- 麦基激励事件要"彻底颠覆主角生活平衡"。恐怖片里，激励事件通常是**不可逆地踏入恐怖世界的那一刻**（第一具尸体 / 走进阴宅 / 收到诅咒）。
- 注意**命运型 vs 偶然型**：纯偶然撞见的恐怖较廉价；更高级的是主角出于某个"可回溯的选择"（为追真相 / 为完成任务 / 误触禁忌）而跨越门槛，让悲剧有其来由。

### 5. 主角不该"作死智商下线"——而是被两难逼入死地
- 恐怖片最大槽点"主角作死"。麦基视角：这不是让主角变笨，而是**用两难困境剥夺他所有"聪明"的出路**——每条路都有代价。
- 用「压力下的选择」逼主角：为了救别人必须回到险地 / 为了掩盖罪必须继续陷进去 / 信与不信之间的致命赌注。角色不是蠢，是被选择困住。

### 6. 高潮 = 幸存代价的不可逆价值改变
- 麦基高潮须不可逆。恐怖片的高潮不必是"战胜怪物"，而常是**主角走到了不可逆的境地**：逃出来了但已经变了（代价）/ 发现真正的恶在别处 / 幸存却背负。
- 最好的恐怖结局，是让"观众以为安全时"再给最后一下——但这一下须符合内在逻辑，不是为吓而吓。

## 常见失败模式（对照自查）

| 失败 | 为什么会失效 | 麦基适配解法 |
|------|--------------|--------------|
| 只有 jump-scare 没有 dread | 瞬时惊吓无情感地基，观众很快免疫 | 先造"不安全感"（四层对立），再落惊吓 |
| 怪物逻辑前后不一 | 无规则（rule）的恐怖力量不可信 | 给恐怖力量**内在规则**，观众才能"预判 & 恐惧" |
| 主角作死智商下线 | 没有两难，只剩降智 | 用「压力下的选择」剥夺聪明出路，而非让角色钝化 |
| 靠血腥廉替 | 视觉冲击无价值代价 | 让暴力的每一笔都付在对立力量上，而非消费 |
| 结尾泄气 | 高潮不可逆被偷换（其实是一场梦 / 都是误会） | 保住"不可逆的价值改变 + 幸存代价" |
| 恐怖感与情感孤立 | 只有怕没有"为谁而怕" | 先让观众想保护/共情主角，恐惧才立得住 |

## 分步做法

1. **确认硬门槛**：先核对是否满足"类型=恐怖/惊悚 且 用户明确要求"双条件，不满足即回退。
2. **定价值轴与恐惧目标**：和用户敲定 主角的自觉/不自觉欲望 + 恐怖力量的对立来源（内在/个人/社会/环境哪层为主）。
3. **定恐怖规则（rule）**：明确恐怖力量的能力边界与弱点——它是怎么运作的、杀不了谁、遵从什么规律。这决定恐惧的可预判性与逻辑自洽。
4. **排结构阶梯**：用 outline-template 的骨架，把吓点按 节拍→场景→序列→幕 逐级加压，避免平铺。
5. **设计主角两难**：为"不降智"画出至少一条"被两难困住"的死路，替换作死桥段。
6. **写高潮与遗留代价**：保证不可逆 + 幸存代价；结尾的最后一下符合内在逻辑。
7. **自查**：用上方"常见失败模式"表逐项核对。

## 输出结构

- 对**诊断**：按 `diagnosis-workflow.md` 骨架，但逐要素体检时额外核对本站第 2、3、5、6 条（未知/揭示、规则、两难、不可逆代价）。
- 对**新创作/改编**：交付一份**契合恐怖结构的修改/骨架建议**，含 恐惧价值轴、恐怖规则、结构阶梯吓点排布、两难场景、结尾遗留代价。

## 麦基依据

- 麦基对立力量与故事价值——恐怖片的威胁只有叠在"对人重要的价值"上才成恐惧。
- 麦基对"偶然型触发"的警惕与"命运型"的偏好——恐怖门槛宜由主角选择跨越。
- 麦基悬念观（观众知情 > 角色）与威慑地使用——与"未知 > 揭示"的恐怖原理协同。
- 麦基不可逆高潮与幸存代价——恐怖结局的"不好收场"正是其力量所在。

## 边界提醒

- 本子类只服务"恐怖片该怎么写"，**不替用户做"要不要做恐怖片/面向谁"的定位决策**（那是创作决策）。
- 不把恐怖片写成"平台爽感/猎奇配方"；本站一切服务于恐惧的情感与价值地基。
- 若用户要求按"惊悚 vs 恐怖"细分（心理惊悚型更重悬念 vs 实体恐怖型更重未知），按用户指向在相应条目上加权。

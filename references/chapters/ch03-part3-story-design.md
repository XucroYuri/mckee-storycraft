# 第三部：故事设计的原理

## 核心思想

这是全书最具实战性的部分。麦基逐层拆解故事设计的每一个结构单元：从激励事件（触发事件）如何启动故事引擎，到幕的设计如何分配张力，到场景如何通过节拍和转折点推进，再到危机、高潮与结局的精确设计。核心引擎是「鸿沟原理」：角色行动 → 期望落空 → 鸿沟（落差）出现 → 角色调整 → 故事推进。

## 本部分介绍的框架

- **激励事件（触发事件）（The Inciting Incident）**
  - 必须彻底颠覆主角生活中的平衡力量
  - 唤起主角的自觉欲望，也可能激发不自觉的欲望
  - 在观众脑海中提出「剧情重要疑问」（这部电影到最后会怎样？）
  - 时机：观众对角色了解得够多、够深，足以做出完整回应的那一刻
  - 设计练习：我的主角可能遇到的最糟的事是什么？如何让它转化为最好的事？

- **幕的设计（Act Design）**
  - 第一幕 ≈ 25% 片长，第一幕高潮出现在 20-30 分钟处（120 分钟电影）
  - 最后一幕最短（≈20 分钟），提供瞬间加速感直抵高潮
  - 每一幕的高潮都是不可逆的价值转折
  - 幕与幕之间的情绪节奏应有起伏变化

- **场景设计（Scene Design）** — 每个场景的要素
  - 转折点（Turning Point）：价值从正到负或从负到正
  - 铺陈（设伏）/ 回报（兑现）（Setup/Payoff）：信息递送的时机决定惊喜还是悬念
  - 情绪动态：场景中的情绪如何流入和流出
  - 节拍（Beat）：角色行为的最小单位，节拍的累积塑造场景
  - 压力下的选择：场景的真正目的是迫使角色作出决定

- **鸿沟原理（The Gap）**
  - 角色采取行动 → 期望世界作出某种反应 → 世界回应了截然不同的东西
  - 这个落差 = 鸿沟 = 故事推进的动力
  - 当鸿沟出现，角色必须调整策略，展开新的行动

- **危机、高潮、结局（Crisis, Climax, Resolution）**
  - 危机：两难选择（主角必须在两个不可兼得的选项中抉择）
  - 高潮：不可逆的价值转折，故事所有力量的终极释放
  - 结局缓冲：高潮后给观众喘息的空间（帷幕缓缓降下）

- **少即是多（Less is More）**
  - 以伯格曼为例：只给观众最少的必要信息，观众的集体潜意识会补完其余
  - 激励事件的通病：延迟中心剧情，塞入过多背景说明
  - 解决方法：问自己"观众真的需要知道这个吗？"

## 关键概念

- **事件**：亨利·詹姆斯 — 事件可以是微小的事，如"一个女人把手放在桌子上，带着某种神情看着你"。时机适合时，即使只是一个动作，也能传达旧生活的崩塌或新生活的开始。
- **剧情重要疑问**：激励事件后，观众心中自动浮现的中心问题（他们会在一起吗？他会成功吗？）
- **必要场景**：观众基于类型和剧情发展而预期出现的场景
- **节拍**：角色行为变化 → 场景的内在生命来自节拍的累积

## 反模式（Anti-patterns）

- **延迟激励事件**：开场花太多篇幅铺垫背景，让观众不耐烦
- **空有转折无铺垫**：突然的转折没有前面的铺陈支撑，成为"机械降神"（deus ex machina，过于巧合的额外帮手）
- **最后一幕拖太长**：高潮后的情节如果延展过长，观众情绪会消散
- **主角被动**：主角一直在"反应"而非"行动"，故事缺乏推动力

## 要点总结

1. 激励事件是整部剧本"修改次数最多的场景" — 值得反复打磨
2. "最糟 → 最好"和"最好 → 最糟"是设计激励事件的两个核心提问
3. 每一幕高潮都必须是不可逆的价值转折
4. 场景的灵魂不在对白，在于节拍累积而成的转折点
5. 鸿沟是故事的心跳 — 没有落差就没有故事
6. 伯格曼的极致简约：几乎什么都不说，却什么都传达

## 一、核心框架（按麦基《故事》提炼）

### 1. 原理 > 规则（Principle over Rule）

麦基开宗明义区别：**规则告诉你"必须这么做"，原理告诉你"经过时间考验，这么做确实行得通"**。写一个好故事应遵循这门艺术的原理，而不是模仿写得好但早已过时的剧本。心急的作者墨守成规，离经叛道的作者冲撞规则，只有真正的艺术家精确掌握形式。

**适用场景**: 面对"该不该这样写"的困惑 → 回到原理，而不是找范本。

### 2. 原型 > 刻板（Archetype over Stereotype）

原型故事发掘普世共通的人生经验，用特定文化独有的方式包装。刻板俗套的故事则因内容与形式的匮乏而显得蹩脚。原型故事能在不同文化圈传播——如同《巧克力情人》中的母女冲突，每个家庭都能理解，细节却前所未见。

**适用场景**: 担心故事太冷门或太小众 → 问自己：冲突够不够原型？细节够不够独特？

### 3. 故事是生活的隐喻（Story as Metaphor for Life）

对事件的选择与安排，是创作者对现实世界的高明隐喻。揭开角色塑造与场景安排的表象，露出的是故事结构背后创作者的宇宙观。好故事不是对现实的逃避，而是承载我们去追寻现实、理解世界的工具。

**适用场景**: 思考故事的主题深度 → 你的结构本身就在表达你对世界的理解。

### 4. 对立原则（The Principle of Antagonism）— 故事设计最重要的准则

> 「主角和主角的故事，只有在对立力量的迫使下，才能在理智上引人入胜、在情感上扣人心弦。」

对立力量不是某个具体的反派，而是**对抗主角意志与欲望的所有力量之总和**。人性本就保守，我们绝不做不必要的事。因此，与主角作对的对立力量越强大、越复杂，角色和故事就越完整。

**适用场景**: 故事平淡、主角不够立体 → 增强对立力量的层次（内在冲突 + 个人冲突 + 社会冲突 + 环境冲突）。

### 5. 激励事件（触发事件）（The Inciting Incident）— 写作难度第二高的场景

激励事件必须彻底颠覆主角生活里所有的平衡力量，唤起主角重新建立平衡的欲望。最恰当的时机：**观众对角色了解得够多、够深，足以做出完整回应时**。提早一个场景不行，延后一个场景也不行。

设计问题：**「我的主角可能遇到的最糟的事是什么？如何让它最后转化为主角遇到的最好的事？」**（反之亦然）

**两种激励事件类型（麦基重要区分）**：
- **偶然型（Coincidental）**：事件由外界的巧合触发，主角被动承受 — 冲动但往往缺乏因果深度
- **命运型 / 决断型（Fateful）**：即便看似巧合，也因主角此前的某个选择而必然导向 — 更具因果穿透力，主流商业片多倾向此型
> 麦基主张：**价值越高（越靠近故事核心的价值），激励事件越应由主角的选择驱动，而非纯巧合**。

**适用场景**: 开场不知道从哪开始 → 先找到那个"彻底颠覆平衡"的事件，再往前倒推最少的必要铺垫。

### 6. 场景思想的关键检查点（Scene）

麦基的场景核心主张是：**一个场景就是一个行动，它必须在一个"转折点"上转变为正或负的"价值"，才算真正成为一场戏**——没有价值转变的场景只是一段无意义的描述性插入。据此，检查一个场景是否成立，可核对以下关键点（这是对麦基思想的实用化提炼，并非原著枚举的固定"五要素"清单）：

- **转折点（Turning Point）** — 该场景结尾的"故事价值"相对开头是否发生了正负逆转？
- **动作（Action）** — 场景由外在行动或内在行动（欲望的抉择）驱动，而非单纯铺陈信息
- **铺陈（设伏）/ 回报（兑现）（Setup/Payoff）** — 信息递送是否在恰当的时机
- **节拍（Beat）** — 角色行为的最小变化单位，一行对话或一个动作即可成一拍
- **压力下的选择（Choice）** — 场景的真正目的是迫使角色做出揭示性格的决定

**适用场景**: 场景写完觉得平淡 → 核对它有没有"转折点"（价值正负转变）与"压力下的选择"；若两者皆无，这段大概率只是填充，而非一场戏。

### 7. 结构阶梯：节拍 → 场景 → 序列 → 幕 → 故事

故事的可变单元从大到小构成一条阶梯，麦基的关键在于区分各层**价值转变的强度**：

- **节拍（Beat）** — 最小的结构单元：一个动作-反应对
- **场景（Scene）** — 以转折点收尾、价值完成一次正负转变的最小完整戏
- **序列（Sequence）** — 一系列场景、以一次**次要**的价值转变（次级转折）收尾的高潮单位
- **幕（Act）** — 一系列序列、以一次**重大**的价值转变（幕高潮）收尾
- **故事（Story）——乃至故事梗概（Grand Story）** — 以"不可逆的终极转变"收尾的完整轨迹

> **为什么缺"序列"会让大纲失控**：很多编剧直接从"场景"跳到"幕"，中间的价值阶梯断档。正因为有"序列"这个次级转折单位，幕内才能形成层层递进的压力，而不是平铺直叙。

**适用场景**: 幕内剧情显得散、找不到"小高潮" → 用"序列"把幕内再切几层，每层做一个次级转折，逐步加压。

### 8. 鸿沟原理（The Gap）— 故事的心跳

期望与结果之间的落差，是故事动力的来源。角色采取行动时，期望世界做出某种反应，但世界回应了全然不同的东西——这个鸿沟迫使角色调整行动，故事由此推进。

**适用场景**: 故事停滞不前 → 让角色的行动产生意料之外的结果，迫使角色（和观众）重新评估。

### 9. 结构光谱：三种故事设计

麦基提出三种故事结构，构成一条光谱：
- **大情节 / 原型情节（Archplot）** — 经典设计，因果清晰，封闭式结局，单一主动主角
- **小情节（Miniplot）** — 简约设计，开放式结局，内在冲突，被动主角
- **反情节（Antiplot）** — 反结构，巧合取代因果，非线性时间，破碎现实

**适用场景**: 决定短剧的结构风格 → 绝大多数商业短剧应选大情节（经典设计），除非刻意实验。

### 10. 人物弧光 = 压力下的选择

人物真相只能通过**压力下的选择**来揭示。低压力下说"我是好人"没有意义；真正揭示性格的，是在两难困境中角色选择 A 而放弃 B 的那一刻。

不自觉欲望 vs 自觉欲望：最立体的角色往往有一个自觉目标（我要赢得比赛）和一个不自觉的真正需求（我需要被父亲认可）。

**适用场景**: 角色感觉扁平 → 设计一个"两难选择"场景，让角色在压力下暴露真实性格。

### 11. 高潮 = 意义的终极体现

最后一幕的高潮是创作难度最高的场景，是故事叙述过程的灵魂；如果失败，整个故事跟着失败。高潮必须是**不可逆的变化**——价值从正到负或从负到正的终极转折。结局之后需要一个"冲突解除场景"作为缓冲，让观众喘口气。

**适用场景**: 规划结局 → 高潮不是"事情结束了"，而是"世界的某种秩序被永久改变了"。

### 12. 控制思想 / 主题（The Controlling Idea）

麦基把"主题"严格界定为一个可陈述的句子公式：**Control Idea = 结局的价值转变（value）+ 导致该转变的原因（cause）**。它不是一句道德教条，而是一个精确的主张——"因为X，所以故事的价值从A变成B"。故事往往在"主题"与"反主题"之间来回摆动，直到高潮处最终裁决。

- **主题句示例**：与其按他人的期待活，生命才被辜负（价值：被辜负的满足 → 自由；原因：放下他人期待）
- 麦基主张：若能一句话说清"你的故事最终要论证什么转换、由什么导致"，你对故事的掌控力会显著提升

**适用场景**: 改大纲/结尾时感觉"主题飘忽" → 尝试把控制思想写成一句"结局转变+原因"的句子，用它穿起所有场景。

> **这对编剧的意义**：多数编剧剧本失控，是因为没有拎清"我真想论证什么"。先写控制思想，再反推每个场景是否为它服务。

## 二、问题驱动索引（按症状找框架）

你手上有个"坏掉的剧本"，但不确定哪里坏了？按症状反向找框架：

| 你的问题（症状） | → 用哪个框架 / 动作 |
|---|---|
| 开篇 / 开场平淡、提不起兴趣 | → 激励事件（触发事件）：事件太晚？是否巧合型而非命运型？倒推最少必要铺垫 |
| 场景读着没劲、像过渡 | → 场景思想核查：该场景结尾价值变了吗？有转折点与压力选择吗？ |
| 幕内松散、找不到小高潮 | → 结构阶梯：用"序列"在幕内切次级转折，逐层加压 |
| 主角扁平、是工具人 | → 人物弧光 = 压力下的选择；自觉/不自觉欲望有没有拉开 |
| 剧情没张力、平平 | → 对立原则：对立力量四层（内在/个人/社会/环境）叠加够不够 |
| 对白太直白、像在解释 | → 潜文本（Subtext）：角色说的和真正想的是否一样；差距越大张力越强 |
| 结尾乏力、看了没感觉 | → 高潮检查：是否不可逆？是否主角自己促成而非巧合？ |
| 故事推进卡住、写不下去 | → 鸿沟原理：让角色的行动产生意料之外的结果，迫使调整 |
| 主题飘忽、不知道故事想问什么 | → 控制思想：把"结局价值转变+原因"写成一句清晰的句子 |
| 铺陈信息太显、反转都能猜到 | → 铺陈/回报技巧：向观众揭示适量信息制造悬念，而非一味卖弄惊喜 |
| 不知道故事往哪去 | → 结构光谱：先定大情节/小情节/反情节，再用结构阶梯规划幕 |

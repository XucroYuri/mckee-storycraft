# 人物弧光 / 两难困境生成器（Character Arc Generator）

面向编剧与创作者的立体角色塑造工具。输入主角现状，输出「自觉欲望 vs 不自觉欲望」对照，再由后者反推制造多个「善 vs 善」两难困境（Dilemma / 善vs善 或 恶vs恶）提案，让角色在压力下的选择（Choice under pressure）被迫暴露人物真相（Character Truth）。

## 适合场景

**适用：**
- 角色单薄、只有外在标签（人物塑造 Characterization），急需补足内在深度。
- 反派不够「坏得有理」、主角不够「善得纠结」，需要靠选择的代价塑造复杂性。
- 需要把「角色想要什么」升级为「角色真正需要什么」，拉出戏剧张力。
- 为某个场景寻找能逼迫角色暴露真相的强烈冲突杠杆。

**不适用：**
- 需求只是补充人物的外在履历、外貌、技能等人物塑造信息，而非内在欲望。
- 类型是纯粹的机械驱动（如工具人、情节需要一笔带过的配角），无需弧光。
- 尚未确立角色的核心目标或价值观，无从推演两难（可先走角色定义流程）。
- 需要的是日常闲笔或氛围塑造，而非以「选择+代价」为核心的结构化冲突。

## 输入

提供主角现状，至少包含三类信息：

1. **人物塑造标签（Characterization）**：外在、被观察到的属性——职业、外貌、语言习惯、社会身份、表层行为模式。
2. **当前目标**：角色此刻执着想得到的、看得见摸得着的东西。
3. **隐藏恐惧 / 渴望**：角色内心深处不愿承认的软肋、创伤、或真正渴望之物；允许从已知信息中合理推断。

若输入缺信息，先依据已给内容补全推断，再标注「推断理由」，避免凭空捏造。

## 分步做法

1. **提取自觉欲望（Conscious Desire）**：从「当前目标」出发，明确角色自认为想要的、能说出口的东西——通常具体、有形、可量度（赢下比赛、获得职位、救出某人）。
2. **提取不自觉欲望（Unconscious Desire）**：从「隐藏恐惧 / 渴望」出发，逆推出角色真正需要却未必意识到的需求——通常抽象、情感性、长期性（被认可、被爱、才配活着）。自觉与不自觉二者分离，正是立体角色的根基；分离得越远，张力越强。
3. **识别对立力量（Opposing Forces）**：把不自觉欲望中藏着的价值观堆成对立面——它要守护的恰恰可能是它要牺牲的（如「认可」与「道德」、'家庭'与'荣耀'）。
4. **由不自觉欲望反推两难场景**：设计处境，逼迫角色「为达成自觉目标，被迫牺牲不自觉需求」（或反之）。核心是：让两个选项都朝着有价值的、也都有代价的方向去，制造真正的撕扯。
5. **校验两个选项的对等性**：两难的两个选项必须都「站得住」——积极价值对积极价值，或消极对消极；若一个明显对、一个明显错，那就不构成两难，应立即废弃并重造。真正的选择来自「两个都想要、只能留一」。
6. **为每个提案标注它逼出什么真相**：写清该场景若选择发生时，会暴露角色哪一层人物真相——通常是不自觉欲望的浮现、或恐惧确实存在。

## 输出结构

对每个角色，产出齐整板块：

**A. 欲望对照**
- 自觉欲望（Conscious Desire）：
- 不自觉欲望（Unconscious Desire）：
- 句：两者的分离点与张力的来源

**B. 两难困境场景提案（2-3 个）**

每个提案包含四行：
- **场景**：一句话说清处境。
- **选择 A / 代价**：选 A 时，角色得到自觉之物，却失去的不自觉之物。
- **选择 B / 代价**：选 B 时，角色守住不自觉所需，却失去自觉之物。
- **逼出的真相**：无论选哪边，暴露的角色人物真相是什么。

**C. 提醒**：两难必须「善 vs 善」或「恶 vs 恶」，两个选项对等、都站得住，且都带有真实的代价——否则退回第 5 步重造。

## 麦基依据

- **人物真相靠压力下的选择揭示**：人物塑造（外在）到何时何地才是人物真相，唯有在压力下、涉及真实价值的选择发生时，人物外在形象才会坍塌，真面目才显现。
- **最立体角色＝自觉目标 + 不自觉真正需求分离**：麦基区分「自觉欲望」（角色以为自己想要的）与「不自觉欲望」（角色内心深处真正需要的）。当二者分离，故事便有了生生不息的驱动力——角色一边追求自觉之物，一边被不自觉需求暗中拉拽。
- **两难即真选择**：真正的选择不是「对 vs 错」——那只反映角色道德底线；而是「善 vs 善」或「恶 vs 恶」之间、在两个都有代价却都有价值的东西间抉择。选择即牺牲，牺牲即揭示。
- **对立力量把价值压到人身上**：真正驱动故事的不是对白、动作或风格——而是由主角的欲望和道德构成的、他人难以招架的取舍时刻；两难制造的对立力量迫使角色在关键时刻现出原形。

## 示例

**角色**：职业运动员。自觉目标：拿到全国冠军。隐藏恐惧：怕被训练时要他「更狠更冷血的教练」比出「你不是那块料」；渴望得到父亲认可（父亲从不说「以你为荣」）。

- **欲望对照**：自觉欲望＝赢得金牌；不自觉欲望＝获得父亲的认可与接纳。分离点：即便没拿金牌、只要父亲拥抱他也会被满足，但他用「夺冠」替代了「求认可」，两者错位。
- **场景 A**：决赛对手是父亲的旧徒弟、曾像家人般养大主角的师哥。
  - 选 A（夺金）：得了冠军，却背叛了师哥于他有恩的旧情——失去「做一个重情义的人」的自我认同。
  - 选 B（放水）：守住对师哥的道义，却葬送自己唯一证明给父亲看的机会。
  - 逼出的真相：他不自觉要的从来不是金牌，而是「终于有一次父亲因他而骄傲」——这让「赢」和「被认可」彻底撕开。
- **场景 B**：赛前父亲突发重病，陪护意味着缺席决赛。
  - 选 A（留下陪护）：得到与父亲和解、兑现被认可的机会——失去唯一夺冠的平台、证明自己「过硬」的机会。
  - 选 B（去比赛）：保住夺冠、替父亲完成梦想的机会——却可能在他临终时缺席，永远失去那声「以你为荣」。
  - 逼出的真相：他「冷血求胜」的外在（人物塑造）只是伪装，内心真正求的是爱——选择印证了他追求认可、胜过追求胜利。
- **场景 C**：教练要求他服用禁药以稳夺金牌。
  - 选 A（用药）：得到金牌与父亲的注视——失去清白、道德与「靠实力赢」的信念。
  - 选 B（拒用）：守住道德与真实——却几乎必然落败、失去父亲认可的最后窗口。
  - 逼出的真相：他的底线不是胜利而是诚实——真相让「道德」浮出，超越他对「认可」的顽固追逐。
- **提醒**：以上每一对选项都互为实对的「善 vs 善」——此处的两难各自有代价、各自有价值，任一选项都能成立；若设计时出现「一方明显正义」的失衡，须即刻重置场景，保证两难的真实撕扯。

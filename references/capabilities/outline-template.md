# 三幕大纲重构模板（Outline Template）

生成可填空的三幕大纲骨架：按"结构阶梯（Story Step Ladder）"与"大情节（Classical Design）"的经典设计，为编剧铺出现激励事件（触发事件）→ 序列（Sequence）→ 幕高潮（Act Climax）→ 高潮（Climax）的固定格子。每格标注应发生的价值转变与自检问题，编剧只往里填内容，不重新发明骨架。

## 适合场景

**用：**
- 编剧手里只有一个概念、一个主角、或一段真实经历，想快速得到一份可执行的三幕骨架。
- 已有零散点子，需要按幕、按序列整理成"每格一个价值转变"的结构。
- 剧本写了一半出现"找不到下一步"的停滞，用骨架反向填空定位断点。
- 需要为短片、短视频、单集等"小结构"快速生成规范大纲。

**不用：**
- 已有完整、定稿的分场大纲（此时应做逐场审校而非重建骨架）。
- 追求反结构、小情节（Miniplot）、实验叙事等"另类设计"——本模板面向大情节经典设计。
- 编剧只想写散文式情节梗概，不打算按幕/序列组织。

## 输入

| 字段 | 说明 |
| --- | --- |
| 类型 / 篇幅 | 电影 / 短片 / 短视频 / 剧集单集；预计时长或场次量 |
| 主角（Protagonist） | 名字、核心欲望、特质缺陷、身份处境 |
| 现状 / 想法 | 一段概念、一个情感、一个主题（控制思想）方向，或一段真实素材 |
| 辅助设定 | 世界观、对立力量（Antagonist/负面力量）、关键道具，可选 |

## 分步做法

1. **锁定控制思想（主题）**：用一句话写出主人公在故事结束时经历的"从旧价值到新价值的转变"，例如"从恐惧到勇气"。这一步决定骨架全部格子的价值极性。
2. **定义主角与对立力量**：写明主角的核心欲望（要什么）、不变还是改变（价值转变的方向）、以及构成对抗的反对力量（别的人物/社会/自然/内心）。
3. **定激励事件**：优先采用命运型（Inciting Incident，因命运/外力引发，非主动选择），写在故事开始不久。明确它如何把主角的既有生活价值撕开一道口子，并确立一个"追索对象（Object of Desire）"。
4. **铺结构阶梯**：把故事按"序列 → 幕 → 故事"组织。确定第一幕、第二幕、第三幕各自的结尾（幕高潮），以及每个幕内的序列节奏。
5. **依次填每一格**：从激励事件逐步走到结局缓冲，每格填入该处应发生的价值转变与具体事件（见"输出结构"的格子清单），同时回答每格自检问题。
6. **核对鸿沟与危机**：检查每处反转是否来自主角"行动后世界比他以为的更复杂"（鸿沟 The Gap）；在中点与二幕高潮处，主角是否被逼入两难选择（危机）。若没有鸿沟与危机，该格视为未完成。
7. **压缩成骨架**：把每格整理为一句动词句（主角做了 X → 价值从负转正/从正转负），作为可交给分场或写作阶段使用的"填空骨架"。

## 输出结构

输出固定为以下填空格，第一格为"当前价值状态"，末格为"结局缓冲"。每个格子含三要素：**应发生的价值转变**、**占位说明**、**自检问题**。

### 填空骨架（大情节经典设计）

```
故事：{故事名}　类型：{类型}　篇幅：{预计时长/场次}

【开场画像】（可选）
- 主角在生活中 {稳定状态}，价值观 {正/负}。
- 占位：展示主角惯常状态与潜在缺陷。

【激励事件】{命运型/偶然型}
- 价值转变：{旧生活价值} → {被打碎，出现缺口}。
- 占位：一次 {外力/偶然} 事件打破平衡，抛出追索对象 {X}。
- 自检：主角是否被动卷入（命运型）？追索对象是否清晰、有代价？

【进展构建单元 1 素材】（激励事件与第一幕高潮之间的空间）
- 占位：主角为回应激励事件采取初步行动 {A}。

【第一幕高潮】
- 价值转变：主要故事价值 {Core Value} 第 {1} 次 {正/负} 摆动。第一幕必须抛出一个转折点，重新确立追索对象的难度。
- 占位：主角行动 {A} 引发 {后果}，被迫扩大赌注 {B}。
- 自检：主要故事价值是否在这里初次正负摆动？主角是否已无法退回旧生活？

【进展：序列逐层加压】
- 序列 1：{主角尝试 B} → 价值 {小摆幅}。
- 序列 2：{主角尝试 C，世界更复杂} → 价值 {小摆幅，比上一步更剧烈}。
- 占位：靠序列逐层加压，每层都比上一层更危险、更接近核心对抗。
- 自检：序列是否严格递增压力而非原地重复？

【中点（两难危机）】
- 价值转变：主角第一次被迫在 {两难选项甲} 与 {两难选项乙} 之间选择，代价不可同兼。
- 占位：事件在中点制造转折——主角明知无解仍必须选。
- 自检：这是"选谁都损失"的两难，而非"好坏分明"的取舍？

【进展：加压至二幕高潮】
- 占位：主角把选择付诸行动，引发更大鸿沟，向第二幕高潮推进。

【第二幕高潮】
- 价值转变：主要故事价值相对中点实现一次 {剧烈摆动}，主角看似达到 / 失去极点。
- 占位：达成阶段性结果，但暴露出仍需突破的最终障碍 {D}。
- 自检：此处是否让观众认为故事几乎可结束，却又埋下最高障碍？

【高潮（Climax，不可逆）】
- 价值转变：主要故事价值达到终极转折并与控制思想一致（如"恐惧→勇气"彻底反转）。
- 占位：主角主动促成最后一搏，变化不可逆。
- 自检：是否由主角促成而非天降奇迹？结果是否不可撤回、观众无法想象逆转？

【结局缓冲（Resolution）】
- 价值转变：新价值稳定成新生活状态，情绪与主题落地。
- 占位：回望改变、交代余波、提示新常态。
- 自检：是否化解了核心情感，而不只是收束情节？
```

### 占位符约定
- `{中文短语}` 表示编剧需填入的事件/价值/选项。
- `{主角 X}` `{对立力量 Y}` `{控制思想 Z}` 由输入字段统一代入。
- 每格一行"占位："为故事内容提示，一行"自检："为质量门。

## 麦基依据

- 三幕结构源于"结构阶梯（Story Step Ladder）：序列（Sequence）组块成幕（Act），幕组块成故事"，幕的边界由幕高潮（Act Climax）划定。
- 激励事件（Inciting Incident）分为命运型与偶然型：本模板优先让主角被动卷入（命运型），以确立无路可退的对抗结构；事件之后需产出"追索对象（Object of Desire）"。
- 鸿沟（The Gap）：主角行动与世界反应之间存在落差，反转由此产生，而非靠巧合。
- 危机（两难选择）＝主人公与其需求最对抗的短暂时刻；中点与二幕高潮处均应出现。
- 高潮（Climax）＝变化压倒性地不可逆转，且必须由主角在故事自身逻辑内促成，而非依靠外力（deus ex machina）。
- 结局缓冲（Resolution）＝高潮之后情绪的余波与主题落地，不可跳过。

## 示例

以一段 2 分钟短视频《深夜便利店》为例，填空骨架如下。

```
故事：深夜便利店　类型：喜剧/微成长　篇幅：2分钟短视频

【开场画像】
- 主角阿明在便利店值夜班，习惯性忍气吞声，价值观 {畏缩}。

【激励事件】{命运型}
- 价值转变：{平静夜班} → {被顾客无理投诉，险些被扣钱}。
- 占位：醉汉打翻货架却反咬阿明，店长限期查监控自证。自检：追索对象＝保住工作 + 讨回公道，代价＝得罪常客？

【第一幕高潮】
- 价值转变：主要故事价值 {自尊} 第 1 次 {负} 摆动。
- 占位：阿明翻监控发现录像，但发现醉汉是店长熟人——告发会失业。自检：核心价值是否初次正负摆动？

【进展：序列逐层加压】
- 序列 1：阿明尝试私下找醉汉理论，被对方威胁。
- 序列 2：醉汉倒打一耙，店长施压要他吃哑巴亏。

【中点（两难危机）】
- 价值转变：阿明在 {保工作} 与 {讨公道} 之间，只能选一个。

【第二幕高潮】
- 价值转变：主要故事价值 {自尊} 实现 {剧烈摆动}。
- 占位：阿明当众放出监控但镜头被人删改，看似无力回天。

【高潮（Climax，不可逆）】
- 价值转变：{畏缩} → {挺身} 与你写的控制思想一致。
- 占位：阿明用自己的手机录像作证，众人围观下直面醉汉，结果不可逆。

【结局缓冲】
- 价值转变：{挺身} 稳定为 {新的自我}。
- 占位：店长重看录像道歉，醉汉收声，阿明笑着继续上夜班——主题"挺直腰杆"落地。
```

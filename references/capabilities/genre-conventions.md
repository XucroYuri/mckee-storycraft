# 类型惯例对照表（Genre Conventions）

> 本参考面向"选型之后"的铺陈阶段，回答一个问题：**既然定了这个类型，这个类型该铺陈什么？** 它给出一张张"该有的期待场景（Obligatory Scene）+ 惯用手法（Convention）"清单，并提示如何在不遗漏的前提下颠覆部分期待。

## 适合场景

**何时用**：编剧已选定故事类型（本 Skill 的 `SKILL.md` 边界默认不做类型定位决策），进入大纲/分集铺陈阶段；需要知道"这个类型离不开哪些场景与手法"，或需要"如何在守住类型骨架的同时做出新意"参考。典型说法："我定了个逆袭爽感短剧，该铺哪些必有的场景？""我的悬疑爱情双类型，主悬疑辅爱情怎么分配？"——这类查询落到本表。

**何时不用**：

- **不作为类型定位决策**——"该做什么类型"是创作决策，不在本参考职权内；先有类型，再来查本表。用本表反推"该选什么类型"是本参考的越界使用。
- **不作为硬模板/公式速查**——本表的"期待场景/惯用手法"是长期证实的类型骨架，不是勾选即成的流水线。逐条照抄即成套路；本表的价值在"知道骨架"而"另辟皮肉与颠覆点"。
- **不用于拒绝背离类型的新尝试**——反类型、混类型、类型戏仿仍是合法创作；本表只是提醒"背离前，先知道自己在背离什么、放弃了哪些期待"。
- **不用于短视频算法爆款预测**——本表给的是类型骨架，不给"投喂算法"的配方；平台分发权重要结合项目上下文另议。

**如何读这张表**：每格不是"必需勾选项"，而是"该类型的观众会自然期待被兑现或催生张力的地方"。使用时只看"这个类型缺了哪一格最伤"，而不是"这一格应该怎样写"。格里给的是"占位与方向"，不给"标准答案"。进阶标【进】的手法是篇幅与想象力的加码项，舍掉不伤类型认同，层层铺满则张力逐级上扬。

## 输入

用户选定后应给出（供对照时框定优先级）：

1. **故事类型（Genre）**：爱情/浪漫、悬疑/犯罪、家庭伦理/剧情、喜剧、恐怖/惊悚、动作/冒险、成长/励志，或短视频平台常见的都市/恋爱、逆袭/爽感、悬疑短剧。
2. **篇幅/平台**：120 分钟院线 / 剧集集数 / 3–5 分钟短剧 / 数千字网文 / 短视频。篇幅决定期待场景的密度与是否可以牺牲部分次要期待。
3. **（可选）背景与目标观众**：背景（城市/古代/仙侠/近未来）改写同一类型的落地；目标观众决定"期待被满足 or 期待被颠覆"的耐受力。类型契约（Genre Contract）在长期观众处更严格——越是熟稔该类型的老观众，对惯用手法的偏离越敏感。

**优先级原则**：篇幅越短，越应"保核心期待、可牺牲进阶期待（Conventions of the Escalating）"。输入缺项时应先澄清（参考 `SKILL.md` 启动协议），不要瞎猜。

**缺项时的处理**：若用户只说了类型、没给篇幅或目标观众，先说清"对照优先级将依赖篇幅假设"，再按最可能的载体给出参考，并提示可复述一遍调整优先级。不要默默代用某一档篇幅的取舍。

## 分步做法

**第 1 步 确认类型与篇幅**。先与用户敲定类型、篇幅、观众。没定类型就动手铺陈，等于"先建墙再选址"。若用户同时给出背景，一并记下——同一类型在不同背景下的落地方式不同（见"麦基依据"）。

**第 2 步 查该类型的期待场景与惯用手法**。按下表定位该类型的：核心冲突场域 → 必铺的核心期待 → 惯用手法 → 进阶加码手法 → 常见失败点。把清单转成大纲上的"待铺陈候选清单"。一张类型如有多个"核心冲突场域"（如都市/恋爱同时含职场与情感），先把两场域各自期待的当铺项分列，再合并排序，避免混为一谈漏掉某一维。

**第 3 步 给核心期待排优先级**。篇幅有限时，先保"类型骨架"（缺失即类型变味）的核心期待；进阶期待（Escalating）视篇幅舍取。短视频/短剧优先满足"每段有张力"的进阶钩子，院线/剧集优先满足"每幕有推进"的渐进结构。若为混类型（如悬疑爱情），把两套骨架各核一遍后，明确主次再排——配角都求全，往往两败。

**第 4 步 对每个核心期待问"如何不照抄、如何编排"**：同一期待场景可以发生在不同的冲突场域、由不同的节拍到达、用不同的对立力量叠加。找出 1–2 个最可颠覆的期待，设计"合理地违背（合理的偏离）"的颠覆点。具体可问三问：这个期待场景发生在哪一层对立力量上？用什么价值转变（正负）驱动它？它最终服务哪个控制思想，而非为占位而存在？

**第 5 步 检查遗漏与平衡**。逐一核对：所有核心期待是否都占位？颠覆点是否落在"可放弃的次要期待"而非"类型骨架"上？是否仍有足够的期待被诚实兑现，让观众的类型契约不落空？顺带核查：最后到达的高潮是否由主角自己的选择与行动促成、是否不可逆（呼应 `references/patterns.md` 的"高潮检查法"）——类型在场的收束更要在这一处站稳。

**第 6 步 落地时反查"鸿沟与两难"是类型骨架的肌肉**。期待场景是骨架，但每个场景要成戏，仍需内化"场景价值正负"、"压力下的选择"、"对立力量叠加"（见 `references/patterns.md`）。骨架列出了该铺什么，patterns 给出了怎么铺，两者配合使用。

> **编排示例（以"悬疑/犯罪·找出真相"为例）**：骨架要求"线索递增加压 + 伪解 + 揭露"。不照抄的编排可以是——把"伪解"从"误导的嫌疑人"改为"误导的动机"（观众猜对凶手却信错动机）；把"线索递增"从"侦探逐一发现"改为"真相关头后反噬主角的日常工作"；把"揭示"从"独白坦白"改为"一场角色被迫在两种忠诚间表态的公堂戏"。骨架占位不变，落地手法全换。颠覆点可放在"通常必宕"的"伪解"上：让伪解成立过久、付出真实代价，激起老观众"这次不敢再信反转"的不安。

## 常见类型的惯例对照表

> 每行"核心冲突场域 / 期待场景 / 惯用手法 / 常见失败（避免刻板复制）"。进阶手法标"【进】"。

| 类型 | 核心冲突场域 | 该有的期待场景（Obligatory） | 惯用手法（Convention） | 常见失败 / 套路 |
|---|---|---|---|---|
| **爱情/浪漫** | 主角与爱人的欲望/障碍（对立力量多来自内心或社会规训） | 遇见并确立互动张力 → 中段的误会/阻碍/第三者【进】 → 失而复得或牺牲 → 告白/和解的应许时刻 | 欢喜冤家设定、情欲与意志的潜文本（说A意B）、命运式重逢、第三者制造鸿沟 | 一见钟情即万事大吉（缺障碍）、误会靠巧合硬拆、人设扁平只有"爱"一个欲望 |
| **悬疑/犯罪** | 主角（侦探/涉事者）与真相之间的认知鸿沟 | 罪案/秘密的揭幕（激励事件）→ 线索出现并递增加压 → 伪解（false solution）让观众信错 → 揭露/反转 → 真相穷尽（每处解读推至极限）【进】 | 悬念（让观众知情而角色不知）优于惊喜、红鲱鱼（误导线索）、视角封锁、真相须可回溯自洽 | 靠巧合破解、线索无法倒推自洽、反转无铺垫（为炸而炸）、侦探零危险 |
| **家庭伦理/剧情** | 家庭系统内的价值冲突（代际、责任、自我成全） | 家庭平衡被事件打破 → 成员各持立场对立 → 沟通失败/错位 → 无法两全的两难抉择 → 关系重建或崩塌 | 对立力量多层叠加（代际/夫妻/手足）、吃饭与家庭仪式场景承载潜文本、牺牲与亏欠 | 说教化、脸谱化"坏人"（缺各自不得已）、转折靠洒狗血而非价值抉择 |
| **喜剧** | 主角的固执欲望与不可调和世界的冲突 | 荒诞前提确立 → 身份误置/计划失控递增 → 闹剧高潮（冲突能量顶峰）→ 温柔化解 | 误解与错位连锁、节拍扑空（expectation swung miss）、打破第四面墙【进】、用"没有退路的极简开场"逼出喜感 | 只有嘴贫无情境、为笑而笑无情感底、把痛苦当笑点而不转化 |
| **恐怖/惊悚** | 主角与入侵性恐怖力量（超自然/心理/环境）对抗 | 反常现象打破日常 → 证实恐惧真相（由不信到信）→ 逃无可逃的逼迫 → 幸存代价（无力回天或身心俱残） | 未知的想象/半揭示优于全揭示、控制信息节奏制造恐惧、恐怖力量须有内在逻辑 | 廉替/血腥依赖、怪物逻辑前后不一、主角作死智商下线 |
| **动作/冒险** | 主角以身体/意志对抗高冲突环境与反派 | 任务/威胁确立 → 异域/高冲突旅程推进 → 逐层升级的危机（楼梯）→ 主角在不可逆高潮中以自己力量逆转 | 空间/时间/自然的层层加压、对立力量叠环境冲突、以身体手段达目的 | 打斗无叙事目的（为打而打）、反派零动机、主角无敌无代价 |
| **成长/励志** | 主角与自我局限（恐惧/自卑/旧信念）的斗争 | 现状的隐性囚禁 → 触发改变的激励事件 → 反复跌倒与自我怀疑 → 承诺时刻（突破旧我）→ 由内而外兑现 | 回报/设伏的细节铺陈、导师/镜像角色、两难选择逼出真实欲望、高潮由主角自致 | 天赋开挂无过程、导师全知无代价、成功靠"最后一刻神迹"而非选择 |
| **都市/恋爱（短剧）** | 都市男女的职场+情感双重张力 | 高频相遇/拉扯确立 → 阶段性和解→再误会【进】 → 情感转危为安 → 甜点/高糖应许 | 立人设钩子（开局即魅力）、误会即转场、多集多波折、结尾强预期勾续看 | 人设单薄、转折靠脚本性巧合、无情感逻辑、为"爽"牺牲可信 |
| **逆袭/爽感（短剧）** | 受压迫主角对社会等级/不公的复仇式反击 | 遭受不公/羞辱（观众共情起点）→ 低调蓄力 → 打脸/逆转兑现 → 层层加码高级对手【进】 → 大快人心的胜局 | 身份隐藏与后来亮明、装弱诱敌上钩、周期快节奏、情绪宣泄优先 | 主角全程无敌无波折、反派降智、逆袭无代价/无道德成本、全员工具人 |
| **悬疑短剧** | 主角与弥天秘密/连环事件的对抗 | 高能开场钩子（命案/失踪）→ 逐步接近核心 → 每 2–3 集一次反转 → 真相收束 → 反转契合人设 | 三分钟一钩子、强欲望与强障碍对撞、反转可回溯、结尾留钩【进】 | 反转过密逻辑崩、为反转牺牲人设一致性、钩子无兑现、收束草率 |

> **对照共性**：无论类型，凡是"缺失骨架即类型变味"的核心期待，优先保；凡因篇幅可舍、舍却不伤类型认同的进阶手法，次而择舍。"反转"在悬疑/悬疑短剧中是高杠杆（既是核心期待又是进阶加码），务必最用心：反转须有铺垫、可回溯、发于人物动机与情境逻辑，而非作者硬掐。
>
> **单类型深研入口**：恐怖/惊悚（恐惧价值轴、未知/揭示与悬念协同、吓点阶梯）见 `references/genre-notes/horror.md`；情景喜剧（节拍密度、单元vs连续架构、笑点情感底）见 `references/genre-notes/sitcom.md`。这些文件均**条件触发**（须 类型匹配 且 用户明确要求），不满足则仍以本表常规处理。
>
> **互补说明**：本表只列"类型层"该铺什么；"场景层怎么写得成戏"（价值正负、压力下的选择、鸿沟、设伏回报）请看 `references/patterns.md` 与 `references/core-frameworks.md`。两者一横一纵配合，覆盖从"选型铺陈"到"逐场落地"的整段创作。

### 篇幅与优先取舍速查（核心期待舍取的档位）

同一类型在不同篇幅下，舍取重心不同。下表给"取舍倾向"，给的是分寸感而非硬线：

| 篇幅/载体 | 优先保 | 可舍 | 取舍原则 |
|---|---|---|---|
| 短片/短剧（3–5 分钟级） | 一个核心期待钩子 + 一次兑现 | 中段反复、多层进阶加码 | 单点打透，不贪全列 |
| 中等篇幅（网文/单集长剧） | 核心期待占位齐全 | 次要进阶手法 | 保骨架完整，进阶择优 |
| 长片/剧集 | 核心+进阶层层铺满 | 几乎不舍 | 多铺几层进阶加码，张力逐级上扬 |

> **一句话收束**：先按载体定"保哪几格"，再回 `patterns.md` 决定"每格怎么铺"。

### 单类型展开范例：以"逆袭/爽感"为例把一列拆开用

一条骨架（核心期待）可拆出可用节拍，示范"如何把表中一列变成铺陈线索"，不可当作公式照抄：

- **遭受不公/羞辱**：压制方式可分等级——公开羞辱（当众贬低）、资源剥夺（断钱断路）、情感绑架（亲人被拿来要挟）。选哪种，看反派跟主角的恩怨深浅。
- **低调蓄力**：蓄力期要设"装弱"的假象——主角明明有能力却不还手，一为示弱诱敌、二为等待一击必中的时机。此处稍给一次"小试牛刀"说服观众他有底牌，又不彻底掀牌。
- **打脸/逆转兑现**：兑现的当众性越强，爽感越足；但兑现须以"主角掌握了情境里别人不知道的信息"为逻辑支点，否则是机械降神。
- **层层加码高级对手【进】**：每次胜利后对手升一档，同时揭开一层更大背景（如家族恩怨、商业阴谋），让"胜利"始终未到终点。
- **大快人心的胜局**：胜局不带"踩人"的廉价感，而落在"主角改变了自己被定义的处境"上——赢回的是选择权，不只是一次低头。

### 单类型展开范例：以"爱情/浪漫"为例说明"如何编排同一期待"

再示范一条骨架的拆解，重点看"如何在骨架不变下换落地手法"：

- **遇见并确立互动张力**：张力来源不必是"冤家互怼"，也可以是"他看得懂她藏在玩笑里的苦"——冲突场域从"性格对立"移到"理解落差"，张力不减而人味更足。
- **中段的误会/阻碍【进】**：阻碍若都来自"第三者/巧合"最偷懒；更稳的阻碍来自主角自身的欲望冲突——他想要这段感情，又想要那份前程，两者不可兼得。对立力量回到角色内心，而非外挂。
- **失而复得或牺牲**：失去的原因应是主角此前的某个选择酿成（可回溯），而非天降车祸、失忆这类机械转折；代价才显得是自己的。
- **告白/和解的应许时刻**：应许时刻落在"行动"而非"对白"——他用一次无法撤回的牺牲或选择代替那句"我爱你"，情感才有重量。
- **颠覆点示例**：常规爱情骨架以"终成眷属"作结；可颠覆的是"应许时刻"本身——让步给"分开也是相爱的一种成全"，若前后铺垫足够（角色对自我成全的执念早已铺陈），老观众会接受这一处背离。

> **两个展开范例的共同教训**：骨架占位不变、落地手法全换，是"守类型而致新意"的通用路径；颠覆点永远要落在"此前已埋好代价与动机"的地方，而非从天而降。范例只是"如何读列"的演示，不是该类型的既定模板——任何照抄都会退回"公式化"。

## 麦基依据

- **先掌握类型的经典形式，再谈颠覆**：麦基主张，只有先精通类型的陈规（conventions）与观众对它的期待，才谈得上"合理地"颠覆；不了解骨架就另起炉灶，通常会既丢类型又无新意。故列骨架在前，颠覆在后。
- **在不遗漏期待场景的前提下，巧妙颠覆部分期待**：类型不是让编剧照抄的模具，而是需要被尊重又适度反叛的"游戏规则"——守住大部分期待，在少数点上出其不意，戏剧张力才强。本表第 4、5 步即把"颠覆"约束在"少而择"。
- **精通原型，不是公式化复制**：通晓典型场景/人物原型给出的是创作原料与方向，而非可勾选的流水线清单；每一部作品的匠心在于把原型落实到具体独特的人、事、情。表末"常见失败"一列，正是照抄原型之病。
- **类型由"惯用手法 + 背景（setting）+ 观众期待"共同定义**：同样一个爱情类型，放在都市、古代、仙侠、近未来背景，其冲突场域、对立力量、期待场景的落地都会改写（如"家族联姻"与"职场禁忌恋"是同一爱情骨架的不同背景变体）。对照本表时应同时考虑背景差异。
- **"合理颠覆"的标杆在长期观众处最严**：对本类型越是熟稔的老观众，对期待未被兑现或惯用手法被背离越敏感；颠覆追求的是"意料之外、情理之中"的更高满足，而非对契约的失信。
- **类型预期的兑现是"惊喜"的容器**：麦基区分悬念与惊喜（见 `references/patterns.md`）——守骨架给了观众稳定预期，这个被满足的期待正是"惊喜"得以被承受与惊艳的地基；没有守出来的稳定区，也就没有能砸出新花的落差。
- **类型是"对立的游戏场"，不是"安全的保温箱"**：麦基的对抗力量四层（内在/个人/社会/环境）在场内是通用的肌肉；爱情不因"爱"而豁免对抗，喜剧不因"笑"而免于代价。任何类型都靠对立力量把期待场景撑成真正的"剧场"，而不是靠类型标签自保。

## 边界提醒

- **本表只答"选型后该铺陈什么"，不替编剧决定做什么类型**。类型与受众的定位决策属于创作决策（见 `SKILL.md` 范围边界），离开本表职权范围。不要从本表"倒推出该选哪个类型"去越界。
- **骨架是参考，不是合同**。本表的"期待场景/惯用手法"是广泛验证的类型惯例；它提醒该占位的元素，但不要求逐条照搬。真正的好故事往往是在守骨架的同时改动 1–2 处。
- **颠覆须有"合理地违背"的自觉**。若要反类型或颠覆期待，先明确自己放弃了哪条期待、以什么代价、换来什么新的观感；无自觉的颠覆通常只是"脚离了泳池却没有跳板"——既丢类型，又无新意。
- **篇幅制约优先级**。短片/短剧无力承载全部进阶期待，优先保核心骨架，宁缺毋滥；长片/剧集则可铺几层进阶加码。在商业短剧场景，宁可牺牲逻辑层面的深沉，也不可少"每 3 分钟一个钩子"的张力期待——但要意识到这是对其叙事品质的取舍。
- **平台调性另议**。短视频平台的节奏/钩子权重（见表中短剧行）是实用经验总结，非同麦基原理；本表只在"叙事质量"层面贡献通用骨架，平台分发权重请结合项目上下文。
- **本表不覆盖"类型定位决策"与"反套路爆款配方"**。这两者分别属于创作决策与算法运营，与麦基叙事原理无直接对应，见 `SKILL.md` 的"范围与边界"。
- **混类型/复合类型须逐类核对**。同时挂两个类型的作品，应按"两套骨架各核一遍核心期待"，并明确主次——主类型保骨架从严，次类型择其高杠杆手法点缀即可。两套都要求满分，往往互相挤压、双双赔本。

## 对照即内省：何时回到本表

本表是"铺陈阶段"的随身清单，不是一次性交卷。三个时刻最该回来对表：

1. **大纲起手时**——借核心期待列定骨架与大节拍，避免"场景热闹但类型骨架不全"。
2. **一稿完成后**——把成稿对照"常见失败/套路"一列自查，缺骨架与掉进套路的通常同一处。
3. **某段尤其平淡、剧作张力上不去时**——回看该类型的"进阶手法【进】"列，判断是骨架占位但在"怎么铺"上偷懒（见 patterns），而非又要加新元素。

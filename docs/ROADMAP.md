## v1.1.0 — 剧本工具化（把"给建议"升级为"能交付"）

当前 Skill 依赖 Agent 临时发挥来"读稿→诊断"。以下能力把它固化为可复用的工具/模板，让编剧拿到的是**可落地的产物**而非泛泛点评。

### P0 · 剧本自动诊断工作流
- 固定一份"读稿 → 逐幕诊断"的脚本化流程：自动切分幕/场景 → 对照「场景价值转变 / 激励事件 / 对立 / 高潮」逐项出结构化报告 → 输出可执行改写清单。
- 交付：`references/` 一个 `diagnosis-workflow.md`（或 scripts/ 脚本），含明确定义的分步协议。
- 价值：把现在"每次动态决定怎么评"变成"每次稳定可复现的诊断"。

### P1 · 三幕大纲重构模板
- 填空式骨架生成器：按「激励事件 → 第一幕高潮 → 进展 → 中点危机 → 第二幕高潮 → 高潮不可逆 → 结局缓冲」产出结构骨架，编剧往里填。
- 交付：`references/` 一个 `outline-template.md`，含每幕的问题清单与填空位。
- 价值：从"分析现有大纲"到"生成可用骨架"。

### P1 · 对白潜文本改写器
- 给定一段平直对白，产出多版本"说 A 意 B"改写：内心潜文本版 / 反击版 / 让步版 / 回避版。
- 交付：一个可重复套用的改写模式（进 patterns.md）。
- 价值：直击编剧最高频痛点（"对白太白"）。

### P2 · 人物弧光 / 两难困境生成器
- 输入角色现状 → 生成"自觉 vs 不自觉欲望"清单 + 多个"善 vs 善"两难场景提案。
- 价值：把"塑造立体角色"变成可引导的产出，而非空谈。

## v2.0.0 — 主动式编剧工作台（愿景）

- **项目级上下文化**：让 Skill 记住你的剧本项目上下文（当前幕/角色/卡点），跨会话延续。
- **类型惯例对照**：内建各类型的「期待场景 / 惯用手法」参照表，编剧选类型即得该类型该铺陈什么。
- **场景价值检测**：一个半自动"场景结尾价值是否转变"的核对工具，帮编剧快速扫全稿漏洞。
- **跨平台适配提示**：同一结构骨架给出「短视频/长剧/小说」的差异标注。

## 决策记录

**为什么不把「类型与受众定位 / 平台调性」列入**：按麦基方法论的边界（SKILL.md 已写明"不刻意覆盖"），这些属于创作决策而非叙事原理，交给编剧在项目上下文里做，本 Skill 只贡献普适叙事质量。这条边界保持 v1.1 到 v2.0 不变。

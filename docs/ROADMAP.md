## v1.1.0 — 剧本工具化（把"给建议"升级为"能交付"）✅ 已构建

6 个"生产工具"已落地到 `references/capabilities/`，把麦基原理固化成可执行的固定流程，编剧可直接套用、反复使用：

### ✅ 剧本自动诊断工作流 `diagnosis-workflow.md`
- 固定"读稿 → 逐幕体检"的脚本化流程；输出报告含 总体印象/逐幕体检/问题清单按严重度/前 2-3 改写建议/质检声明。
- 病灶以"病灶句 + 违反原理 + 影响"三元组记录；先诊断后改写。

### ✅ 三幕大纲重构模板 `outline-template.md`
- 填空式骨架：激励事件 → 第一幕高潮 → 进展(序列加压) → 中点危机 → 第二幕高潮 → 不可逆高潮 → 结局缓冲。
- 每格带"该让什么价值转变 + 自检问题"。

### ✅ 对白潜文本改写器 `dialogue-subtext.md`
- 平直对白 → 多版本"说 A 意 B"改写（内心潜文本/反击/回避/让步）。
- 保留原信息量、只改表达；配合节拍塑形张力。

### ✅ 人物弧光 / 两难困境生成器 `character-arc.md`
- 输入角色现状 → 自觉/不自觉欲望对照 + 多个"善vs善"两难场景提案（含逼出什么真相、选A失B代价）。

### ✅ 类型惯例对照表 `genre-conventions.md`
- 各类型的「核心冲突场域 / 期待场景 / 惯用手法 / 常见失败」对照，含大陆短剧常见的都市/逆袭/悬疑短剧。

### ✅ 场景价值检测工具 `scene-value-check.md`
- 逐场景扫描"结尾价值是否正负转变"，标记无转折的填充段，并给"转成真场景/删除/并入"建议。

## v3.0.0+ — 研究性延伸（三条并行的研究线 🔬）

以下三条不是"一次做掉的功能"，而是可以长期推进、各自成系的研究方向。每条都建立在现有能力之上，但向外延伸到不限于"编剧案头工作"的边界。

### 研究线 A · 类型片 × 方法论适配研究

**目标**：不做"皮相的类型清单"，而是对差异极大的类型片逐一深研——少儿动画、恐怖片、情景喜剧、医疗剧、西部片、音乐剧等——回答两个问题：① 这类专属哪些常见问题（失败模式）？② 《故事》的方法论如何针对性适配，让这类能写得更好？

**关键问题**：
- 少儿动画的"价值正负转变"往往不适合用成人世界的生死浮沉，如何在同一方法论下换价值坐标系？
- 恐怖片的"未知 > 揭示"原则，与麦基"观众知情 > 角色"的悬念观如何协作或冲突？
- 情景喜剧的"节拍密度高、转场频繁"，是否挑战麦基"幕 = 不可逆价值转变"的节奏假设？多季制如何重构？
- 每种类型的"期待场景"哪些是硬约束、哪些可颠覆（深化现有 `genre-conventions.md` 的维度）。

**落地形态**：把现有 `genre-conventions.md` 从"表格速查"升级为"类型适配研究"参考库；每种类型一个 `genre-notes/` 小节，含 常见失败模式 + 方法论适配要点 + 反例示范。

**✅ 验证子类已实现（恐怖/惊悚 + 情景喜剧 + 少儿动画）**：`references/genre-notes/{horror,sitcom,child-animation}.md` 落地，各含 类型专属失败模式、方法论适配要点（恐惧价值轴 / 喜剧节拍与单元vs连续架构 / 少儿价值坐标下移与恐惧可控）、双条件硬门控触发（① 类型匹配 ② 用户明确要求），为后续其他类型（医疗剧、西部片、音乐剧…）铺路打样。

**与现状关系**：直接深化 v1.1 已落地的 `genre-conventions.md`。

### 研究线 B · 编剧 × 导演工作流对接（导演语汇对齐）

**目标**：让编剧在写作时就预判导演拿到剧本后的工作——分镜、视觉化、节奏取舍——在剧本里给导演"更易于开展工作的条件"，本质是提高剧本通过导演审查的概率。

**关键问题**：
- 编剧如何用"可视化的动作描写/可卡景别的节拍"而非纯内心陈述，让导演更省力地抽分镜？
- 如何判断"哪些信息导演可以/应该自行二度创作"，避免过度给死于导演的戏路？
- 剧本的节奏标注（此处宜多机位、此处宜长镜、此处情绪留白）如何写成"可执行提示"而非"侵权越权"？
- 如何保留文学作品感，同时产出"导演讲戏"可读的版本？

**落地形态**：新增 `references/` 一个"导演语汇对齐"参考 + 剧本几类"导演友好写法"的示例（分镜友好动作描写、节奏留白、可视觉化的潜文本）。

**边界提醒**：这只做"语汇对齐与过审友好化"，不替导演做创作决策；与 SKILL.md"范围与边界"中"不碰平台调性"精神一致——是给导演更好的输入，不是越权执导。

### 研究线 C · 剧本 × AIGC 影片生成映射

**目标**：让剧本创作与未来的 AIGC 影片生成形成更好映射——剧本能更顺滑地生成"分镜 prompt / 视频生成 prompt"。

**关键问题**：
- 剧本里哪些位置最适合"埋"视觉/运镜/氛围描述，让 AIGC 抽取分镜 prompt 时命中率高？
- 如何把麦基的"节拍/场景价值/情绪动态"固化成可提示 AIGC 情绪镜头的"机器可读标注"（而不破坏剧本可读性）？
- 为 AI 短片创作，剧本是否应当某种"结构化编剧"——分段、带镜头倾向、带情绪曲线标注——才最利于生成？
- 现有"少即是多、潜文本、让观众自行推断"的文学美感，如何在 AIGC 世界不丢失？

**落地形态**：探索一种"剧本双写"——供人读的文学文本 + 供 AIGC 抽取的结构化层（情绪/镜头/场景价值的机器可读注解）。属前沿探索，需随 AIGC 能力演进迭代。

**边界提醒**：这一条是前沿实验，可能与"不碰特定平台调性"边界有张力；但"AIGC 生成语汇"≠"某平台调性"，本线聚焦"叙事结构 → 生成提示的忠实映射"，而非平台分发技巧。

## 决策记录

**为什么不把「类型与受众定位 / 平台调性」列入**：按麦基方法论的边界（SKILL.md 已写明"不刻意覆盖"），这些属于创作决策而非叙事原理，交给编剧在项目上下文里做，本 Skill 只贡献普适叙事质量。这条边界保持 v1.1 到 v2.0 不变。

**v3.0 研究线如何与边界相处**：
- 研究线 A（类型适配）是**深化**"选型后怎么创作"，不越界做"选什么类型"的定位决策——仍在边界内。
- 研究线 B（导演语汇）是**延伸**到"为导演更好输入"，只做语汇对齐与过审友好，不替导演执导；属边界的谨慎外扩。
- 研究线 C（AIGC 映射）是**前沿实验**，聚焦"叙事结构→生成提示"的忠实映射，区别于"某平台调性"；属边界的审慎试探。
- 三条若推进，都需在**新产物自带"边界与失效场景"说明**，维持"给创作者更好工具、不越权做其创作决策"的底线。

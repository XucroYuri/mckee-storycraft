# 设计规格 — McKee Story Skill 简体优化

**日期**: 2026-08-12
**仓库**: mckee-storycraft
**状态**: 已批准

## 背景
本 Skill 收录麦基《故事》编剧理论，用于辅助编剧创作更扣人心弦的故事。当前版本存在繁体用语、缺乏诊断入口、交互无约束等问题。

## 决策
1. **简体中文化 + 大陆措辞纠偏**（全文件）
   - 文件：SKILL.md、patterns.md、cheatsheet.md、glossary.md、chapters/ch01-04.md、README.md
   - 繁体→简体 + 措辞习惯偏正（屏幕/氛围/铺垫/伏笔/强调等）
   - 术语**双译名并用**：首次出现标注"译名1（译名2）"，正文后文统一用译名1，术语表保留中英对照。如：激励事件（触发事件）、铺陈（设伏）/回报（兑现）、鸿沟（落差）
2. **结构优化**（嵌入 SKILL.md，不新增知识文件）
   - 新增「问题驱动索引」：编剧按症状找框架的反向入口
   - 新增「边界澄清」：明确本 Skill 不做什么
   - 修正事实错误：README 的 `ch07`（不存在）→ 真实章节 ch01–ch04；章节索引与文件对齐
3. **编剧交互优化**（重写 SKILL.md 外壳，简体为主）
   - 启动协议：收集最小必需参数（类型/篇幅时长/目标观众/主角一句话）
   - 支持**剧本诊断模式**：结构化体检输出
   - 输出约束 + 麦基质检清单
   - 更新 argument-hint
4. **README 仓库名更正**：`mckee-story` → `mckee-storycraft`（仓库已改名）
5. **实现方式**：Write 全量重写每个文件

## 交付物
- SKILL.md：新增索引/协议/质检 + 简体重写
- patterns.md / cheatsheet.md / glossary.md：简体纠偏 + 术语统一
- chapters/ch01-04.md：简体纠偏 + 术语统一
- README.md：简体 + 仓库名更正 + ch07 修正

## 验收
- 无繁体残留（`grep` 繁体常用字为空）
- 术语全书一致（激励事件/铺陈/鸿沟等双译名并在前文统一）
- 章节索引 vs 文件树一致；README 的 `ch07` 已不存在
